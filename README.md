# BibleApp — программа для изучения Библии

Приложение на Qt 6 / C++17 для углублённого изучения Библии: чтение модулей
BibleQuote, параллельные переводы, номера Стронга, словари и комментарии,
встроенный конвертор модулей BibleQuote в SQLite.

## Возможности

- Чтение модулей BibleQuote (`bibleqt.ini` + HTML-файлы книг).
- Автоматическое определение кодировки: UTF-8 (с BOM и без), UTF-16, Windows-1251, KOI8-R.
- Надёжный разбор глав и стихов по маркерам `<h4>`, `<sup>`, `<p>`, якорям `A NAME`,
  `<!--PART-->` и inline-маркерам.
- Комментарии и словари: вступление выносится в главу/стих `0`, статьи словаря
  `.idx` + `.htm` открываются как отдельные книги.
- Strong's: ссылки `w:///?s=H7225`, поддержка номеров без префикса
  (префикс определяется по книге: ВЗ → `H`, НЗ → `G`).
- Очистка HTML: сохраняются только inline-теги (`i`, `b`, `sup`, `sub`, `a`, `br`).
- Навигация по фактическим номерам глав и стихов, отображение «Введение».
- Аудит результата конвертации.

## Структура

```
src/            исходный код приложения
resources/      шрифты, встроенные модули и словари (SQLite)
CMakeLists.txt  сборка CMake
```

## Сборка

Требования: CMake ≥ 3.16, компилятор с поддержкой C++17, Qt 6
(Widgets, Gui, Core, PrintSupport, Sql, Sql-SQLite).

```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build -j"$(nproc)"
./build/bibleapp
```

## Установка из пакета

```bash
sudo apt install ./bibleapp_1.5.33_amd64.deb
```

## Сборка .deb для Linux Mint 21.3 и 22.3

Mint 21.3 использует Qt 6.2, Mint 22.3 — Qt 6.4. Бинарник, собранный на 22.3,
содержит метку `Qt_6.4` и не запускается на 21.3. Чтобы один пакет работал на
обеих системах, собирайте его на Mint 21.3 (метка `Qt_6.2`).

```bash
./build_deb_universal.sh              # зависимости + сборка + .deb
./build_deb_universal.sh --skip-deps  # если зависимости уже установлены
./build_deb_universal.sh --no-deb     # только собрать бинарник
./build_deb_universal.sh --install    # собрать и установить пакет
```

Скрипт определяет серию системы, ставит зависимости, проверяет требования
бинарника (`Qt_6.x`, `GLIBC_x.y`) и собирает `.deb` с зависимостями-альтернативами
`libqt6core6 | libqt6core6t64` (совместимость с Ubuntu 22.04 и 24.04).

Проверка готового бинарника:

```bash
readelf -V build/bibleapp | grep -o 'Qt_6\.[0-9]*'
```
