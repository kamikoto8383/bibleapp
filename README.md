# ModulariuM

**ModulariuM** — настольная программа для **офлайн-изучения Библии** под Linux (Ubuntu-подобные системы, Linux Mint 21/22 и аналоги). Работает без интернета: тексты, словари и инструменты находятся на компьютере.

---

## Предназначение

Программа нужна тем, кто хочет:

- читать Писание в разных переводах **рядом** (2–3 окна);
- разбирать **оригинальные языки** (подстрочник, греческий/еврейский, Стронг);
- пользоваться **комментариями, словарями и симфониями**;
- сохранять **закладки**, **историю чтения** и искать по тексту;
- подключать модули из экосистемы **«Цитата из Библии» (BibleQuote)** и **MyBible**, не уходя в онлайн-сервисы.

---

## Основные возможности

### Чтение и окна

- До **трёх окон** с независимыми модулями
- **Синхронизация** по книге / главе / стиху между окнами (для библейских текстов, комментариев, словарей)
- **Синхронная прокрутка** (вкл/выкл в меню «Окно»)
- Выделение **активного окна**
- Запоминание размера окон, модулей и настроек после выхода
- Фон текста «как бумага», чтобы глаза меньше уставали
- Интерфейс на **русском языке**

### Библиотека модулей

- **Моя библиотека** — выбор книги/модуля по категориям:
  - Библия
  - Словаря и справочники
  - Комментарии
  - Толкования
  - Подстрочники
- **Менеджер модулей** — установка, удаление, конвертация
- Встроенный **Русский синодальный перевод** (66 книг), слова Иисуса **красным**
- Конвертеры:
  - **m.biblequote** — модули «Цитаты из Библии»
  - **m.mybible** — модули MyBible (SQLite)

### Подстрочник и Стронг

- Подстрочники с **кликабельными** словами (греческий, еврейский, латиница-транслит)
- Карточка слова со **Стронга на русском**
- Подбор номера Стронга по форме слова / глоссе, если номера нет в тексте
- Словари Стронга по всей Библии (встроенные базы)

### Поиск, закладки, параллели

- Поиск по **словам и фразам** по всему модулю
- Подсветка найденного и прокрутка к месту
- **Закладки** (в т.ч. из выделенного текста), переход с подсветкой
- **История** прочитанных мест (сохраняется после закрытия)
- **Параллельные места** по клику на номер стиха (база параллелей)

### Оформление и удобство

- Смена шрифта (в т.ч. Noto Serif, Gentium Plus, иврит)
- Увеличение / уменьшение шрифта
- Светлая тема оформления, системные элементы управления
- Стрелки **предыдущая / следующая глава** внизу текста
- Выбор книги с разделением **Ветхий / Новый Завет**
- Печать выделенного текста

### Конвертер BibleQuote

- Разбор `BibleQt.ini`, все 66 книг (и добор из HTML, если INI неполный)
- Режим **«как в источнике»** для переводов вроде **«Радостная Весть»** (диапазоны `1-6а`, сноски `2 *`, без пустых стихов)
- Индикация этапов: анализ → конвертация → аудит
- Сохранение стилистики исходного модуля, где это возможно

## Технически

| | |
|---|---|
| Платформа | Linux (deb, amd64), Mint 21.3 / 22.x и Ubuntu-подобные |
| Интерфейс | Qt6, русский язык |
| Данные | Локальные SQLite-модули, без обязательного интернета |
| Имя приложения | **ModulariuM** |

### Структура репозитория

```
src/            исходный код (Qt 6 / C++17)
resources/      шрифты, встроенные модули и словари (SQLite)
CMakeLists.txt  сборка CMake
```

### Сборка

Требования: CMake ≥ 3.16, C++17, Qt 6 (Widgets, Gui, Core, PrintSupport, Sql).

```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build -j"$(nproc)"
./build/bibleapp
```

### Установка из .deb

```bash
sudo apt install -y ./bibleapp_*_amd64.deb
```
